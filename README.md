# Python CLI Calculator

A simple command-line calculator built with Python that performs basic arithmetic operations: addition, subtraction, multiplication, and division.

## Features

* Addition, subtraction, multiplication, and division
* Continuous calculation using a `while` loop
* Supports multiple calculations without restarting the program
* `Q` or `q` option to exit the calculator
* Handles division-by-zero errors using `try-except`
* Handles invalid numeric input using `ValueError`
* Uses separate functions for each arithmetic operation
* User-friendly command-line interface

## Technologies Used

* Python
* Functions
* `while` loop
* Conditional statements
* Exception handling (`try-except`)
* User input

## How to Run

```bash
python calculator.py
```

Choose an operation, enter two numbers, and the calculator will display the result. The program continues running until `Q` or `q` is entered.

## Learning Objectives

This project demonstrates fundamental Python programming concepts including functions, loops, conditional logic, user input, and exception handling.
